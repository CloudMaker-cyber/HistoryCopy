# HistoryCopy 使用说明

一款 Windows 历史剪贴板软件:后台自动记录你复制过的文字和图片,
需要时打开就能找回来再次粘贴。淡蓝色简洁界面,开箱即用。

## 1. 怎么用

1. 把 **HistoryCopy.exe** 放到一个普通文件夹(建议放自己的数据文件夹,如 `D:\HistoryCopy`)
2. 双击运行。第一次打开需要等几秒(程序在解压自己),之后运行就快了
3. 运行后**没有主窗口**,程序躲在屏幕右下角的系统托盘(小图标,蓝色剪贴板形状,
   可能藏在托盘"^"小箭头里)
4. 点击托盘图标即可打开历史窗口;平时不用管它,它会在后台默默记录你的复制

## 2. 常用操作

| 操作 | 方法 |
|---|---|
| 打开历史窗口 | 左键单击托盘图标,或托盘右键菜单 → 打开历史 |
| 使用一条记录 | 点击卡片 → 内容自动复制到剪贴板,窗口自动隐藏 → 在目标窗口按 Ctrl+V |
| 置顶 | 点击卡片上的"置顶";再点一次取消置顶 |
| 删除 | 点击卡片上的"删除",确认后移除 |
| 搜索 | 顶部搜索框输入关键词,匹配文字会高亮显示 |
| 图片预览 | 图片卡片点"预览"看大图 |
| 隐藏窗口 | 按 Esc 或点右上角 ✕ |
| 退出软件 | 托盘右键 → 退出 |

## 3. 设置(托盘右键 → 设置)

- **保留期限**:1 / 3 / 5 天。超过期限且未置顶的记录会自动清理(每天检查一次,
  也可点"立即清理过期"手动清理)
- **开机自启**:勾选后开机自动在后台运行(会写入注册表,不想要时取消勾选即可)
- **清空所有历史**:一键删除全部记录与图片,不可恢复

## 4. 数据存放在哪

数据保存在 **exe 同级的 `data` 文件夹**里(第一次运行自动创建):

- `data\history.db` —— 所有文字记录
- `data\images\` —— 所有图片
- `data\settings.json` —— 你的设置

**备份**:直接复制整个 `data` 文件夹即可;恢复时放回 exe 同级即可。

## 5. 常见问题

**Q: 为什么本地选中的图片文件复制后没有记录?**
A: 本地文件复制放进剪贴板的是"文件引用",不是图片内容,软件目前只记录"图片内容"
(如网页右键复制的图片、截图)。如需记录本地图片文件,可作为后续功能增加。

**Q: 杀毒软件提示风险?**
A: PyInstaller 打包的程序偶尔会被部分杀毒软件误报。点击"允许/信任"即可。
这是开源打包工具的常见情况,程序本身仅访问剪贴板与本地文件。

**Q: 打开 exe 后没有反应?**
A: 因为程序默认在后台运行,看右下角托盘图标。若没有图标,确认已被杀毒软件拦截。

**Q: 开机自启为什么不生效?**
A: 需在 设置 → 勾选"开机自动启动",并确认 exe 没有被移动过位置。

**Q: 重装/换电脑怎么迁移?**
A: 备份 `data` 文件夹 → 装好新版 → 把 `data` 放回 exe 同级目录。

## 6. 开发环境运行(可选)

有 Python 环境的开发者可运行 `run.bat` 或 `python src\main.py`。
