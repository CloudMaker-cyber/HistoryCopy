# 开发计划 (Development Plan)

> 文档版本:v1.0
> 更新日期:2026-08-02

## 1. 开发原则

1. **小步快跑** —— 每个阶段只做一件事,完成并确认后再进入下一阶段
2. **稳定优先** —— 每阶段结束时保证程序可运行、不破坏已有功能
3. **记录留痕** —— 每阶段完成/待办都记入 `devlog/` 日志
4. **随时可验证** —— 每阶段都有明确验收点,由用户确认

## 3. 每日工作流程

1. 打开 `devlog/`,新建/打开当日日志
2. 先记录**待办事项**(承接前一天未完成)
3. 逐项完成,完成后更新日志与 `docs/dev-plan.md` 勾选
4. 结束前填写"今日完成""遗留问题""明日计划"
5. 涉及方案变更时,同步更新 `docs/` 对应文档

## 4. 变更管理

- 任何需求/技术变更,先更新对应文档并说明原因
- 变更后通知用户确认再实施
