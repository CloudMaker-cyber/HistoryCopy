# 需求文档 (Requirements)

> 项目名称:HistoryCopy —— Windows 历史剪贴板软件
> 文档版本:v1.2(已与用户确认)
> 更新日期:2026-08-08
> 变更说明:v1.1 新增"批量删除"功能(F8);v1.2 新增"图像文字提取"功能(F9)

## 1. 项目概述

一款运行在 Windows 电脑上的历史剪贴板软件。后台常驻监听系统剪贴板,
自动记录用户复制过的文字和图片,支持按时间浏览、搜索、置顶、删除,
并可设置数据保留期限,超期自动清理。

## 2. 目标用户

- 不懂代码的普通电脑用户(小白友好)
- 有频繁复制粘贴、需要找回历史复制内容的场景

## 3. 功能需求

### 3.1 核心功能

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| F1 | 自动记录 | 后台监听复制操作,自动记录文字和图片 | 高 |
| F2 | 存储期限 | 可设置保留天数(1 天 / 3 天 / 5 天),到期自动清理 | 高 |
| F3 | 历史浏览 | 主窗口按时间降序(新的在前)展示历史卡片 | 高 |
| F4 | 再次使用 | 点击卡片,内容复制回剪贴板,由用户手动 Ctrl+V 粘贴 | 高 |
| F5 | 置顶 | 置顶卡片固定在最上方,新复制的内容不能超过它,取消置顶后恢复时间排序 | 高 |
| F6 | 删除 | 每张卡片可单独删除 | 高 |
| F8 | 批量删除 | 可进入"多选模式"勾选多条记录,一键删除所选(勾选可跨页记忆,删除前有确认) | 中 |
| F9 | 图像文字提取 | 图片卡片上提供"识别文字"按钮,点击后识别图片中的文字并展示,支持一键复制 | 中 |
| F7 | 搜索 | 输入关键词实时过滤文字卡片;图片卡片按时间顺序显示 | 中 |

### 3.2 运行方式需求

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| R1 | 后台常驻 | 软件开机自动启动,在系统托盘显示图标,静默记录 | 高 |
| R2 | 快速呼出 | 需要时点击托盘图标(或快捷键)打开主窗口查看历史 | 高 |
| R3 | 用完即关 | 点击卡片复制完成后,窗口自动隐藏,回到原窗口 Ctrl+V | 中 |

### 3.3 数据管理需求

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| D1 | 去重更新 | 重复复制相同内容时,更新该条记录的时间,不重复新增 | 高 |
| D2 | 图片存储 | 图片以文件形式保存在软件目录下,记录引用 | 高 |
| D3 | 数据位置 | 数据保存在软件目录内,方便备份 | 中 |

## 4. 界面需求 (UI)

- 简洁、直观,主色调淡蓝色
- 卡片展示内容预览 + 复制时间
- 详见 `docs/design-spec.md`

## 5. 非功能需求

| 编号 | 类型 | 描述 | 优先级 |
|---|---|---|---|
| N1 | 易用性 | 无需安装环境,双击 exe 即可运行 | 高 |
| N2 | 稳定性 | 长时间后台运行不崩溃、不卡顿 | 高 |
| N3 | 低干扰 | 监听复制不打断用户正常工作 | 高 |
| N4 | 性能 | 记录内容多时,界面打开和搜索依然流畅 | 中 |
| N5 | 备份 | 数据目录结构清晰,用户可自行复制备份 | 中 |

## 6. 已确认的关键决策

| 问题 | 用户选择 |
|---|---|
| 技术方案 | Python 图形界面,打包成独立 exe |
| 粘贴方式 | 点击卡片仅复制回剪贴板,手动 Ctrl+V |
| 运行方式 | 后台常驻 + 托盘图标 |
| 置顶规则 | 置顶区固定在最上方,不受新内容影响 |

## 7. 验收标准

1. 后台运行时,复制文字/图片后能在历史列表中找到
2. 设置 1/3/5 天保留期,到期记录被清理
3. 点击卡片能将内容复制回剪贴板并成功粘贴
4. 置顶的卡片始终在列表最上方
5. 搜索能准确过滤文字记录
6. 软件以 exe 形式双击运行,开机自动启动
7. 长时间运行稳定,界面淡蓝色、简洁直观
8. 进入多选模式可勾选多条记录并一键删除,跨页勾选记忆有效,删除前弹出确认
9. 点击图片卡片的"识别文字"按钮,可识别并展示图片中的文字,结果可一键复制
10. OCR 仅在用户主动点击时执行,不自动扫描;识别结果不出电脑(本地识别)
