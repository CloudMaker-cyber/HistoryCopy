# 界面设计规范 (Design Specification)

> 文档版本:v1.0
> 更新日期:2026-08-02

## 1. 设计原则

1. **简洁** —— 界面元素少而精,信息一目了然
2. **直观** —— 用户无需学习,打开就会用
3. **淡蓝色主色调** —— 清爽、安静、不刺眼

## 2. 色板 (Color Palette)

| 用途 | 颜色 | 色值 |
|---|---|---|
| 主背景 | 淡蓝灰白 | `#F0F6FB` |
| 主色(按钮/选中/强调) | 淡蓝 | `#5B9BD5` |
| 主色-加深(悬停) | 中蓝 | `#4A87C3` |
| 卡片背景 | 纯白 | `#FFFFFF` |
| 卡片悬停 | 极淡蓝 | `#EAF3FB` |
| 文字-主 | 深灰蓝 | `#2B3A4A` |
| 文字-次(时间) | 灰蓝 | `#8CA3B8` |
| 分割线 | 淡灰蓝 | `#E3EDF6` |
| 置顶标记/强调 | 蓝 | `#3E8EC7` |
| 删除/危险 | 红 | `#D9534F` |

## 3. 字体规范

| 用途 | 字体 | 大小 |
|---|---|---|
| 窗口标题 | 微软雅黑 SemiBold | 14pt |
| 卡片正文预览 | 微软雅黑 | 11pt |
| 时间标签 | 微软雅黑 | 9pt |
| 搜索输入框 | 微软雅黑 | 11pt |

## 4. 主窗口布局

```
+------------------------------------------+
| [🔍 搜索框............]   设置 | 清除历史  |
+------------------------------------------+
|                                          |
|  ┌ 置顶区(如有置顶卡片) ──────────────┐  |
|  │ [置顶] 卡片1  📌              ⋯  │  |
|  │ [置顶] 卡片2  📌              ⋯  │  |
|  └──────────────────────────────┘  |
|  ──── 时间线分割提示 ────              |
|  [卡片]  时间降序                    |
|  [卡片]                             |
|  [卡片]                             |
|  ...                                |
+------------------------------------------+
```

- 顶部:搜索框 + 操作按钮
- 中间:滚动列表(置顶区在上,普通区按时间降序)
- 底部(可隐藏):记录总数、清理状态提示

## 5. 卡片设计

### 5.1 文字卡片

```
+────────────────────────────────────+
| 📄 内容预览(最多 2 行,超出省略号)     |
| 今天 14:23                        |
|   [复制] [置顶📌] [删除🗑]           |
+────────────────────────────────────+
```

### 5.2 图片卡片

```
+────────────────────────────────────+
| [ 缩略图  (宽高等比,最大 160px)  ]   |
| 今天 14:23                        |
|   [复制] [置顶📌] [删除🗑]           |
+────────────────────────────────────+
```

### 5.3 交互状态

| 状态 | 表现 |
|---|---|
| 默认 | 白底、圆角 8px、浅边框 |
| 悬停 | 淡蓝背景 `#EAF3FB` |
| 点击复制 | 短暂高亮反馈(200ms) |
| 置顶卡片 | 左上角蓝色 📌 标记,顶部留白区分 |

## 6. 交互规范

| 操作 | 行为 |
|---|---|
| 点击卡片主体 | 内容复制到剪贴板,窗口自动隐藏 |
| 点击"复制"按钮 | 同上,窗口保持打开 |
| 点击"置顶"按钮 | 卡片移到置顶区;再次点击取消置顶 |
| 点击"删除"按钮 | 弹出确认(若已置顶需额外提示),确认后删除 |
| 搜索框输入 | 实时过滤文字卡片,图片卡片仍按时间显示 |
| Esc 键 | 隐藏窗口(不退出程序) |

## 7. 托盘图标

- 常驻系统托盘,图标为蓝色剪贴板样式
- 左键单击:打开/隐藏主窗口
- 右键菜单:
  - 打开历史
  - 设置(保留天数等)
  - 退出

## 8. 空状态与边界

| 场景 | 表现 |
|---|---|
| 暂无记录 | 居中显示淡蓝色提示"暂无复制记录" |
| 搜索无结果 | 显示"未找到相关记录" |
| 图片加载失败 | 显示灰色占位图 |

## 9. 无障碍与易用性

- 所有操作可通过鼠标完成
- 主要操作按钮文字清晰,图标为辅助
- 高 DPI 屏幕适配(Windows 缩放)
